## Dữ liệu và code tham khảo

- SEC API: https://www.sec.gov/search-filings/edgar-application-programming-interfaces
- SEC fair access: https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data
- Notre Dame SRAF, LM dictionary 1993–2025, cập nhật March 2026: https://sraf.nd.edu/loughranmcdonald-master-dictionary/
- https://github.com/haesoopyun/10k-Textual-Analysis — khung workflow, biến phụ thuộc volatility khác bài này.
- https://github.com/m4a1ak471994/lm2011-replication — phương pháp và cấu trúc replication, không lấy kết quả của repo làm kết quả nhóm.
- https://github.com/mariasfondrini/financial-nlp-lab — package/tests và NLP extensions.
- VADER: https://github.com/cjhutto/vaderSentiment — từ điển tổng quát có xử lý cường độ và ngữ cảnh; dùng implementation NLTK.
- Yahoo download library: https://github.com/ranaroussi/yfinance — dữ liệu học thuật thăm dò, không thay thế nguồn tài chính có license.
